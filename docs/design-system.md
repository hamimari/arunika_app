# Arunika Design System

App style:
- premium kids educational app
- warm and magical
- modern mobile UI
- emotionally friendly

Design references:
- Duolingo Kids
- Khan Academy Kids
- Pok Pok
- Pokémon cards

Rules:
- use large rounded corners (24px)
- use layered cards
- use soft shadows
- use gradients subtly
- use large illustrations
- use breathing whitespace
- avoid clutter

Spacing:
- 8pt spacing system
- minimum padding 16
- section spacing 24

Buttons:
- rounded pill buttons
- large touch targets
- soft gradients

Cards:
- soft shadow
- rounded 24
- cream/light background

Typography:
- large bold headers
- rounded friendly fonts
- minimal text

Animation:
- smooth transitions
- floating effects
- soft motion only

Color palette:
- orange primary
- blue secondary
- cream background
- gold accent
